# accnomos_mobile

Flutter Android app for Accnomos: bookkeeping and VAT for UK small
businesses, a thin client over the same runtime API as the web app.

- Web parity: [`PARITY.md`](PARITY.md) — every web page/action against
  the phone (done / missing / web-only-by-design).
- Release notes: [`RELEASE_NOTES.md`](RELEASE_NOTES.md) (current 0.3.4+9).
- Gates: `flutter analyze`, `flutter test`, and
  `flutter build apk --debug --target-platform android-arm64`
  (Flutter at `C:\src\flutter\bin`).
