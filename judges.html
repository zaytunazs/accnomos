For judges

Try Accnomos in one click

This sandbox is specially for testing. It opens six months of books for a fictional company, Bramblewood Joinery Ltd (every document in it is labelled as fictional sample data), with no Microsoft sign-in and no two-step verification. Each visitor gets their own copy, kept in memory on our server and reset after 2 hours, so nothing you change reaches anyone else.

Start the demo opens Review, with six documents waiting. What to try from there, in order (review and approve a receipt, ask by voice or text, invoices, bank matching, a VAT return to HMRC's sandbox, goals, and the personal demo of a household's own money), is the demo guide, the page “Try the demo” opens for everyone.

What is real here, and what is simulated

  • Real: the app, the checks, the ledger and VAT arithmetic, and the AI (the model this server is set up with). Scanning the documents still in 00 Inbox sends them to that AI. Which AI model does what.
  • Pre-read: the six documents waiting in Review were read when the sample books were made, from the fields printed on them, so you can start without waiting for a model.
  • HMRC sandbox: the VAT return goes to HMRC's sandbox, HMRC's own test service: a test user made for your demo, HMRC's sign-in page, HMRC's periods and receipt. No real tax is filed; live filing needs HMRC's approval. If the sandbox can't be reached, the card says so and simulates the submission instead.
  • Simulated: email is never sent (you'll see “Sent (demo — not actually sent)”), the bank feed connects a test bank, and the Companies House and VAT-number look-ups are switched off.
  • Not stored: nothing about you. There is no Microsoft account behind the demo, and its books are gone after 2 hours idle or when you press Reset demo.

How to run it, and where the evidence is

  • What it does and how to try it, including how to run the whole thing in test mode with no accounts: README › Try it.
  • AI models, where each runs and what is measured against what is unit-tested: docs/AI_MODELS.md. Every accuracy figure is on synthetic documents.
  • What pre-existed and how each part was built, with timestamps: docs/PROVENANCE.md.
  • What is not tested against real services (HMRC is sandbox only; most features are tested on fakes): docs/HONESTY.md.
  • Android: the APK on the repository's Releases page opens the same demo with Try the demo.

Your own books instead

Signing in with Microsoft sets up real books in a folder in your own OneDrive: Accnomos keeps no copy, and HMRC submissions go to HMRC's sandbox. You can still load the same sample books there with one button. Connect your OneDrive.
